Ejercicio 1

Tarjeta simple

Una tarjeta de producto básica — sin grid todavía (eso es S20), solo un bloque suelto con imagen, título y precio, apilados con flex-col.

1

El App.jsx del Paso 5 de la guía devuelve un solo elemento — el <nav> — dentro del return (...). React no permite devolver dos elementos sueltos uno al lado del otro, así que para agregar la tarjeta debajo del navbar hay que envolver ambos en un fragment (<>...</>), una etiqueta especial que agrupa sin agregar HTML real.

frontend-react/src/App.jsxantes (Paso 5 de la guía)
function App() {
  return (
    <nav className="...">
      ...
    </nav>
  )
}

Ahora en src/App.jsx, envolver el <nav> en <>...</> y agregar la tarjeta justo debajo, dentro del mismo fragment, pero fuera del <nav> (después de su etiqueta de cierre):

frontend-react/src/App.jsxreemplazar todo
function App() {
  return (
    <>
      <nav className="flex items-center justify-between px-8 py-4 bg-white border-b border-slate-200">
        <div className="text-xl font-extrabold text-verde">
          TechStore Pro
        </div>
        <ul className="flex gap-6 text-sm font-semibold text-texto-dim">
          <li>Inicio</li>
          <li>Productos</li>
          <li>Nosotros</li>
          <li>Contacto</li>
        </ul>
        <button className="bg-verde text-white py-2 px-5 rounded-lg font-bold text-sm">
          Ingresar
        </button>
      </nav>

      <div className="flex flex-col gap-2 p-4 rounded-xl shadow-md max-w-xs">
        <img src="https://placehold.co/300x200" className="rounded-lg" />
        <h3 className="font-bold text-lg">Mouse Inalámbrico</h3>
        <p className="text-verde font-extrabold">$89.900</p>
      </div>
    </>
  )
}

export default App
⚠️Ojo con las etiquetas: <> abre el fragment, </> lo cierra — van justo antes de <nav> y justo después de </div> de la tarjeta. Si el navbar sigue apareciendo solo, revisa que no falte ninguna de las dos.
✅Cómo verificar: debe verse el navbar arriba, y debajo una tarjeta con esquinas redondeadas, sombra suave, la imagen arriba, el título en negrita y el precio en verde SENA — todo apilado en columna, con separación uniforme entre elementos (gap-2).
💡gap-2 separa los elementos hijos de un flex sin necesitar margin en cada uno — una sola clase reemplaza tres reglas CSS distintas.
Ejercicio 2

Botón secundario

TechStore Pro ya tiene un segundo estilo de botón en frontend/css/styles.css: .btn-secundario, un botón "outline" (solo borde, sin relleno). Se reconstruye con el mismo patrón que .btn-primario en el Paso 4 de la guía.

1

El original en CSS tradicional:

Antes — CSS tradicionalfrontend/
/* styles.css */
.btn-secundario {
  background-color: transparent;
  color: var(--color-primario);
  border-color: var(--color-primario);
}

Ahora en Tailwind — en src/App.jsx, agregar este botón justo debajo del </div> que cierra la tarjeta del Ejercicio 1, todavía dentro del fragment (antes del </> final):

frontend-react/src/App.jsxagregar
      </div>  {/* cierre de la tarjeta del Ejercicio 1 */}

      <button className="bg-transparent text-verde border-2 border-verde py-3 px-6 rounded-xl font-bold">
        Ver más detalles
      </button>
    </>  {/* cierre del fragment — esta línea no se mueve */}
✅Cómo verificar: el botón debe verse con fondo transparente, texto y borde en verde SENA — el borde debe notarse claramente (border-2), no una línea apenas visible.
Ejercicio 3

Footer simple

Un pie de página básico, reutilizando el color texto que ya está configurado en el @theme del Paso 3 de la guía.

1

En src/App.jsx, agregar el footer justo debajo del </button> del Ejercicio 2 — sigue siendo dentro del fragment, antes del </> final:

frontend-react/src/App.jsxagregar
      </button>  {/* cierre del botón del Ejercicio 2 */}

      <footer className="flex justify-between items-center p-6 bg-texto text-white">
        <p>© 2026 TechStore Pro</p>
        <p className="text-sm">Hecho con Tailwind CSS</p>
      </footer>
    </>  {/* cierre del fragment — esta línea no se mueve */}
✅Cómo verificar: el footer debe tener fondo oscuro (el mismo --color-texto: #1a1a2e del Paso 3), texto blanco, y sus dos párrafos separados a los extremos opuestos (justify-between) en vez de uno debajo del otro.
💡justify-between empuja el primer y último elemento a los extremos del contenedor flex — es la misma clase que usa el navbar del Paso 5 para separar el logo de los links.
🚀 Recordatorio: todo este contenido de práctica (tarjeta, botón secundario, footer) se puede borrar de App.jsx al final de la sesión — era solo para practicar. El navbar del Paso 5 de la guía es lo único que debe quedar.
